# 마무리 작업 분담 체크리스트

> 현재 6개 미니게임의 핵심 로직/판정/HUD는 전부 구현되어 있다(`docs/minigames/*.md` 참고).
> 남은 건 (1) 빠진 캐릭터 동작 이미지 제작 + Unity 연결, (2) 실측 튜닝, (3) 데모 실행 환경
> 준비다. 아래는 **팀원(이미지 생성, Codex)** / **나(포토샵 보정 + 개발)** / **공용(둘 다
> Claude Code로 Unity 작업)** 세 축으로 나눈 제안이다 — 인원 배분은 참고용이니 편한 대로
> 바꿔도 된다. 체크박스는 그대로 두고 완료되는 대로 `[x]`로 바꿔가면서 쓰면 된다.

## 0. 먼저 정할 것 — 캐릭터 동작 표현 방식

아래 이미지 작업 전에 이것부터 정해야 한다. 지금은 모든 동작이 "관절 리깅"(팔꿈치/어깨
피벗 회전)으로만 표현되고, 프레임 만화컷 이미지(예: `jump_images`, `stone_throw_images`)는
이미 몇 개 그려져 있어도 **아직 아무 게임에도 연결되지 않았다** — 연결하려면 공용
`CavemanSilhouette`에 "특정 순간 몇 프레임을 통짜로 재생" 기능이 먼저 필요하고, 이건
여러 미니게임에 걸친 결정이라 한 번에 정해야 한다.

- [ ] **결정**: (a) 지금처럼 관절 리깅만 쓸지, (b) 프레임 애니메이션을 도입해서 순차적으로
      게임마다 바꿀지, (c) 게임마다 다르게 갈지(예: 눈빛싸움 P1처럼 클로즈업 만화컷이 자연
      스러운 것과, 돌던지기처럼 전신 리깅이 이미 잘 맞는 것을 구분)
- [ ] 결정되면 `CavemanSilhouette`(또는 신규 컴포넌트)에 "n초 동안 프레임 배열 재생 후
      기본 상태 복귀" API를 공용으로 하나 만들어서 이후 모든 게임이 재사용

## 1. 이미지 생성 (팀원 — Codex)

> 원본 경로 규칙과 참고 스타일은 [`docs/필요한_이미지_목록.md`](필요한_이미지_목록.md) 참고.
> 이미 있는 같은 캐릭터의 다른 동작 프레임(`front/`, `stone_throw_images/` 등)을 Codex에
> 같이 넣어서 화풍을 맞출 것.

- [ ] **눈빛싸움 — character2용 `eye_fight` 6프레임** (`image/characters/character2/
      eye_fight_images/eye_fight_1~6.png`, 270×454px) — character1 것을 참고 이미지로 넣고
      캐릭터만 바꿔서 생성 ([필요한_이미지_목록.md 1-1](필요한_이미지_목록.md#1-1-눈빛싸움--character2용-eye_fight-애니메이션))
- [ ] **돌던지기 — 정면 던지는 동작으로 재생성** (`character1`, `character2` 각각
      `stone_throw_1~5.png`, 581×687px) — 기존 파일은 옆모습이라 정면(카메라 쪽을 보고
      던지는) 구도로 다시 그려야 함 ([1-2](필요한_이미지_목록.md#1-2-돌던지기--옆으로-던지는-모션을-정면-던지는-모션으로-교체))
- [ ] **돌 or 바나나 — 좌우 분할화면(오버더숄더) 구도용 전신 동작**: 이 게임은 화면을
      좌/우로 나눠 "내가 상대를 마주보는 시점"으로 재구성됐다([05_돌or바나나.md 5장](minigames/05_돌or바나나.md#5-화면-구도)
      참고) — 캐릭터별로 **앞모습 와이드샷**(전신, 던지기/피하기/먹기)과 **뒷모습
      바스트샷**(상체 클로즈업) 두 시점이 필요. 구체적 포즈/파일명 제안은
      [필요한_이미지_목록.md 1-3](필요한_이미지_목록.md#1-3-돌-or-바나나--전신-동작-세트-던지기-2종--피하기--먹기)에
      있지만 **분할화면 구도로 바뀌면서 시점(앞/뒤) 요구사항이 늘어났으니 재확인 후 진행**
- [ ] **코코넛깨기 — 식탁 소품에 맞는 내려치는 동작** (`character1`, `character2` 각각
      `coconut_1~4.png`, 368×521px 유지) — 기존 파일은 식탁/쟁반 소품과 비율·시점이 안 맞음

## 2. 이미지 보정 (나 — 포토샵)

- [ ] 팀원이 생성한 각 프레임에서 배경 제거(투명 PNG화), 캔버스 크기/여백을 같은 세트
      내 다른 프레임과 통일
- [ ] 기존 파츠(`front/`, `back/`, `faces/`)와 색감/선 굵기가 튀지 않는지 비교 보정

- [ ] 보정 끝난 파일을 `image/characters/character{1,2}/...` 원본 경로에 반영

## 3. Unity 연결 (공용 — Claude Code로 진행)

이미지가 도착하는 대로, 또는 0번 결정이 끝나는 대로 진행:

- [ ] 새 프레임들을 `Assets/Resources/Characters/`(또는 게임별 폴더)로 임포트
- [ ] 0번에서 만든 "프레임 재생" API를 각 게임 스크립트에서 호출하도록 연결
      (돌던지기 발사 순간, 코코넛깨기 타격 순간, 눈빛싸움 P1 위험도 단계, 돌바나나
      던지기/피하기/먹기 순간, 과일따기 점프 중)
- [ ] **자세따라하기(PoseCopy) — 포즈 6종의 목표 관절 오프셋 데이터 테이블** (이미지 작업이
      아니라 순수 데이터 작업, 최우선 — 이게 없으면 판정 자체가 동작 안 함):
      [06_자세따라하기.md 9장/13장](minigames/06_자세따라하기.md#9-필요한-이미지) 참고 — 한
      사람이 각 포즈를 실제로 취하고 `CapturePose`로 한 번씩 녹화해서 상수로 굳히면 됨
- [ ] 각 미니게임 문서 9번(필요한 이미지) 표에서 상태가 "❌ 미사용"/"보류"인 항목들을
      연결 후 ✅로 갱신
- [ ] [게임별_에셋_세부_계획.md "다음 품질 개선 우선순위"](게임별_에셋_세부_계획.md#다음-품질-개선-우선순위)
      순서대로: 결과판 교체 → HUD 폰트/외곽선 통일 → 캐릭터 피벗 미세조정 → 16:9 외 화면비
      점검 → 오브젝트 풀 → 사운드/화면흔들림/파티클

## 4. 백엔드(vision-server) 실행 환경 준비 (각자 자기 PC/노트북)

> 자세한 절차는 [`vision-server/README.md`](../vision-server/README.md),
> [`게임_구동방식_정리.md` 3장](게임_구동방식_정리.md#3-lan-연결-설정-방법) 참고. "백엔드"라고
> 부를 만한 서버를 새로 만드는 건 아니고, 각자 노트북에서 포즈 인식 프로세스를 띄우고
> 서로 LAN으로 연결하는 설정이다.

- [ ] 각자 노트북에 `vision-server/.venv` 만들고 `pip install -r requirements.txt`
- [ ] `models/face_landmarker.task` 다운로드 확인(없으면 입벌림/눈감김이 계속 기본값 —
      눈빛싸움/과일따기/돌바나나가 제대로 안 됨). `pose_landmarker_lite.task`는 이미 레포에 있음
- [ ] Unity를 실행할 PC 한 대 정하기(둘 중 하나, 또는 별도 PC)
- [ ] 같은 공유기/핫스팟(같은 LAN)에 두 노트북 + Unity PC가 붙어 있는지 확인
- [ ] Unity PC 방화벽에서 UDP 9100 인바운드 허용(Windows Defender 방화벽 고급 설정)
- [ ] 리허설: `python main.py --pc-ip <Unity PC IP> --player-id p1` /
      `--player-id p2`로 두 노트북에서 동시 실행 → Unity `Hub` 씬 Play → 카메라 프리뷰에
      랜드마크가 잘 잡히는지, Unity 콘솔에 UDP 바인딩 에러가 없는지 확인
- [ ] 실제 데모 장소(발표 환경) 조명/카메라 거리로 한 번 더 리허설 — 조명에 따라 인식률이
      크게 달라짐

## 5. 실측 튜닝 & QA (둘 다, 실제로 플레이해보면서)

각 미니게임 문서의 "조정 가능한 값" 표에 있는 임계값은 전부 추정치라 실측이 필요하다:

- [ ] 돌던지기 — `fireIntervalSeconds`, `dodgeTiltThreshold`
- [ ] 자세따라하기 — `poseMatchTolerance`, `knockbackRatio` (체형별 오차 편차 특히 주의)
- [ ] 과일따기 — `tierHeightThresholds`, **카메라 프레이밍**(정점에서 머리가 프레임 밖으로
      안 나가는지 — [03_과일따기.md 13장](minigames/03_과일따기.md#13-미해결--todo) 참고)
- [ ] 코코넛깨기 — `hitDistance`, `releaseDistance`
- [ ] 돌 or 바나나 — `turnTimeoutSeconds`
- [ ] 눈빛싸움 — `earThreshold`, `loseAfterClosedSeconds`, `loseAfterTotalClosedSeconds`
      (사람마다 눈 크기 편차 큼 — 캘리브레이션 필요 여부 재확인)
- [ ] 6개 게임 각각의 문서 12번 "구현 완료 기준(Acceptance Checklist)"을 실제로 플레이하며
      하나씩 체크
- [ ] 최종적으로 `Hub` 씬에서 6판 풀 매치를 처음부터 끝까지 한 번 통과(중간 씬 전환/결과
      화면까지 포함해서)
