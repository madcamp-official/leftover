# 4. 눈빛싸움 (Staring Contest)

> 코드: `Assets/Scripts/Minigames/StaringContest/StaringContestGame.cs`, `StaringContestHud.cs`,
> `Assets/Scripts/Common/EyeCloseTimer.cs`.
> 씬: `Assets/Scenes/StaringContest.unity`.

## 0. 한 줄 요약

따로 조작할 게 없다 — 그냥 카메라를 계속 응시하기만 하면 된다. 눈을 먼저, 더 오래 감는
쪽이 진다.

## 1. 플레이어가 하는 일

| 동작 | 결과 |
|---|---|
| 눈을 뜨고 카메라를 응시 | "눈 감음 위험" 게이지가 0으로 유지 |
| 눈을 감음(EAR이 `earThreshold` 밑으로 떨어짐) | 감은 채로 있는 시간에 비례해 위험 게이지가 차오르고 표정이 점점 감기는 것처럼 바뀜 |
| 눈을 감은 채로 `loseAfterClosedSeconds` 이상 연속으로 버팀 | 그 순간 즉시 패배 확정(더 기다리지 않음) |
| 감다가 다시 눈을 뜸 | **연속** 위험 게이지는 즉시 0으로 리셋되지만, 라운드 전체 **누적** 감은 시간은 리셋되지 않고 그대로 남음 |
| 눈을 감았다 뜨기를 아슬아슬하게 반복(깜빡임으로 연속 판정을 계속 회피) | 누적 감은 시간이 계속 쌓여 결국 `loseAfterTotalClosedSeconds`를 넘기면 패배(무한정 버틸 수 없음) |

다른 5개 게임과 달리 이 게임은 전신 캐릭터가 아니라 **얼굴 클로즈업 두 개 + 그 사이의
시선 충돌 이펙트**로 화면이 구성된다.

## 2. 입력 신호 (PoseInputHub API)

| 신호 | 메서드/필드 | 이 게임에서의 의미 |
|---|---|---|
| 눈 감김 순간값 | `state.IsEyeClosedNow(earThreshold)` | `EyeCloseTimer`가 매 프레임 내부적으로 호출 — 게임 스크립트가 직접 부르지 않음 |
| 눈 감음 연속 지속시간 | `EyeCloseTimer.ClosedDuration` | 연속으로 눈을 감고 있는 시간(초). 눈을 뜨는 순간 0으로 리셋됨 |
| 눈 감음 누적 지속시간 | `EyeCloseTimer.TotalClosedDuration` | 라운드 동안 감고 있었던 시간의 총합(초). 눈을 떠도 리셋되지 않음 — 깜빡임 반복을 통한 무한 버티기 방지용 |
| 눈 감음 연속 판정 | `EyeCloseTimer.IsClosedContinuously(seconds)` | `ClosedDuration >= seconds`이면 참 |
| 트래킹 여부 | `state.IsTracked` | false면 `EyeCloseTimer`가 `ClosedDuration`을 즉시 0으로 리셋(`TotalClosedDuration`은 그대로 유지 — 아래 "예외" 참고) |

이 게임은 `PlayerPoseState`를 직접 조회하지 않는다 — 씬에 배치된 `EyeCloseTimer`
컴포넌트(P1용 하나, P2용 하나)가 매 프레임 `PoseInputHub.Instance.Get(player)`를 읽어
`ClosedDuration`/`TotalClosedDuration`을 갱신하고, `StaringContestGame`은 그 결과값만 읽는다.
순간 EAR만 보면 자연스러운 눈 깜빡임도 "감음"으로 잡히므로, 판정은 반드시 이 지속시간
기준이어야 한다.

## 3. 규칙 / 상태 흐름

상태 머신 없이, 매 프레임 P1/P2의 `ClosedDuration`/`TotalClosedDuration`을 비교하는 단순
판정만 돈다. 패배 조건은 "연속" 기준과 "누적" 기준 **둘 중 하나만 만족해도** 성립한다 —
연속 기준만 있으면 눈을 감았다 뜨기를 반복해서 계속 리셋시키는 식으로 무한정 버틸 수
있기 때문에, 눈을 떠도 리셋되지 않는 누적 기준을 함께 둬서 이를 막는다.

```
[진행 중] --p1Closed 또는 p2Closed--> 라운드 종료
  (Closed = ClosedDuration >= loseAfterClosedSeconds
         또는 TotalClosedDuration >= loseAfterTotalClosedSeconds)
[진행 중] --elapsed >= maxMatchSeconds(둘 다 안 감음)--> 라운드 종료(무승부)
```

매 프레임 처리 순서:

1. 연속 위험 비율 `p1ContinuousRatio = p1Timer.ClosedDuration / loseAfterClosedSeconds`,
   누적 위험 비율 `p1TotalRatio = p1Timer.TotalClosedDuration / loseAfterTotalClosedSeconds`를
   각각 계산(P2도 동일). 최종 `p1Ratio = Mathf.Max(p1ContinuousRatio, p1TotalRatio)` — 둘 중 더
   위험한 쪽을 HUD 게이지/표정에 반영한다.
2. HUD 위험 게이지와 얼굴 표정을 `p1Ratio`/`p2Ratio`로 갱신. P1은 `eye_fight_1`~`eye_fight_6`
   6단계 전체 스프라이트 교체(`Mathf.CeilToInt(ratio * 6f)`를 1~6으로 clamp), P2는 기존대로
   `face_eyes_closed_1of4`~`4of4` 4단계 표정 교체(0.01 이하면 기본 얼굴, 초과면
   `Mathf.CeilToInt(ratio * 4f)`를 1~4로 clamp) — 이 차이는 6번 섹션 참고.
3. `p1Closed = p1Timer.IsClosedContinuously(loseAfterClosedSeconds) ||
   p1Timer.TotalClosedDuration >= loseAfterTotalClosedSeconds`, `p2Closed`도 동일하게 확인.
4. 둘 다 감았으면(정확히 같은 프레임에 조건 만족) → 무승부. 한쪽만 감았으면 → **감은 쪽이
   패배**(즉 안 감은 반대쪽이 승리).
5. 아무도 안 감은 채로 `maxMatchSeconds`(기본 60초)가 지나면 → 무승부로 라운드 종료.

## 4. 승리 / 패배 조건

다음 둘 중 하나를 먼저 만족한 사람이 **즉시 패배**하고 상대가 승리한다:

- 눈을 `loseAfterClosedSeconds`(기본 0.4초) 이상 **연속으로** 감고 있음, 또는
- 라운드 동안 감고 있던 시간의 **총합**이 `loseAfterTotalClosedSeconds`(기본 2.5초)를 넘김
  (깜빡임을 아무리 반복해도 결국 이 누적치로 패배가 확정된다 — 눈을 떠도 이 누적치는
  리셋되지 않음).

정확히 같은 프레임에 둘 다 조건을 만족하거나, 아무도 안 감은 채 `maxMatchSeconds`가 지나면
무승부.

## 5. 화면 구도

- 카메라: `orthographicSize = 3`.
- 배경: 카메라 뷰를 채우는 배경 스프라이트 한 장(`image/games/staring_contest/background/`).
- 얼굴: P1 스프라이트가 `(-1.6, 0.2, 0)`, P2 스프라이트가 `(1.6, 0.2, 0)`에 좌우 대칭
  배치, 가로 폭 `headWidth`(기본 2.2)에 맞춰 종횡비 유지한 채 균일 스케일(`ArtAssets.FitWidth`).
  P2는 다른 게임들의 전신 캐릭터 대신 머리만 크게 확대한 클로즈업이라 세로로 짧지만, P1은
  `eye_fight_N` 프레임 자체가 몸통+탁자까지 포함된 세로로 긴 이미지라 같은 폭 기준으로도
  훨씬 더 길게 보인다(아래 6·7번 참고).
- 시선 충돌 이펙트: 두 얼굴 사이 정중앙 `(0, 0.2, 0)`에 고정 배치된 정적 스프라이트(크기
  2×2) — 애니메이션이나 판정 연동 없이 항상 표시.

## 7. 연출 / 피드백

- **위험 게이지**: `p1Ratio`/`p2Ratio`(연속·누적 비율 중 더 높은 쪽)에 실시간으로 정확히
  비례해서 채워짐(즉시 반영, 보간 없음).
- **P1 표정/전신 변화**: 파츠 조립이 아니라 `eye_fight_1`~`eye_fight_6` 6장짜리 만화컷
  스프라이트를 `p1Ratio`에 비례해 통째로 교체한다(캐릭터 파츠 렌더링은 이 게임의 P1에서는
  완전히 쓰이지 않음). `ratio=0`이면 `eye_fight_1`(눈 크게 뜬 기본), 비율이 올라갈수록
  `eye_fight_2`→`3`→`4`→`5`→`6` 순으로 전환.
- **P2 표정 변화**: character2용 `eye_fight` 프레임 원본이 없어서 기존 방식 유지 — 비율이
  0.01 초과가 되는 순간부터 `face_eyes_closed_1of4`~`4of4` 4단계로 점점 눈이 감기는 것처럼
  바뀌고, 눈을 뜨면(비율이 0.01 이하로) 즉시 기본 얼굴로 복귀(파츠 기반 머리만 교체).
- **시선 충돌 이펙트**: 정적 이미지 한 장만 항상 표시(연출 애니메이션 없음).

## 8. 조정 가능한 값

| 필드명 | 기본값 | 단위 | 의미 |
|---|---|---|---|
| `earThreshold` | 0.18 | EAR 비율 | 이 밑이면 그 프레임은 "눈 감음"으로 판정(`EyeCloseTimer`에 그대로 전달) |
| `loseAfterClosedSeconds` | 0.4 | 초 | 이 시간 이상 연속으로 눈을 감고 있으면 즉시 패배 |
| `loseAfterTotalClosedSeconds` | 2.5 | 초 | 라운드 동안 누적으로 감고 있던 시간이 이 값을 넘으면 즉시 패배(깜빡임 반복 방지) |
| `maxMatchSeconds` | 60 | 초 | 아무도 안 감았을 때의 라운드 제한시간(초과 시 무승부) |
| `resultDisplaySeconds` | 2.5 | 초 | 승패 문구 표시 후 다음 라운드로 넘어가기 전 대기 시간 |
| `ruleBannerSeconds` | 2.5 | 초 | 라운드 시작 시 규칙 배너를 표시하는 시간 |

P1/P2 얼굴 스프라이트 크기는 코드가 아니라 씬의 `EditableLayout`에서 직접 배치/스케일을
조정한다 — 예전에 있던 `headWidth`(코드로 `FitWidth`를 적용하는 값) 필드는 실제로는 어디서도
호출되지 않는 죽은 필드였어서 정리했다(6종 `eye_fight` 프레임이 전부 같은 픽셀 크기라 실제
버그로 드러나진 않았음).

## 10. 예외 / 엣지 케이스

- **한쪽이 트래킹 안 됨(`IsTracked == false`)**: `EyeCloseTimer`가 그 프레임에
  `ClosedDuration`만 즉시 0으로 리셋한다(`TotalClosedDuration`은 그대로 유지) — 즉 카메라
  밖으로 나가면 "눈을 뜬 것"과 동일하게 처리되어 연속 위험은 초기화되지만, 이미 쌓인 누적
  감은 시간까지 지워지지는 않는다(트래킹 끊김을 패배 회피 수단으로 악용할 수 없음).
- **눈을 감았다 뜨기를 임계값 직전까지 반복**: 매번 뜨는 순간 `ClosedDuration`은 0으로
  리셋되어 연속 패배 조건은 피할 수 있지만, `TotalClosedDuration`은 감고 있던 시간만큼
  계속 쌓이므로 결국 `loseAfterTotalClosedSeconds`로 패배가 확정된다 — 무한정 버틸 수 없다.
- **정확히 같은 프레임에 둘 다 패배 조건 만족**: 무승부 처리(승자 없음으로
  `MatchController`에 보고).
- **`maxMatchSeconds` 경계값**: `elapsed >= maxMatchSeconds`가 된 프레임에 아무도 안 감은
  상태면 그 즉시 무승부로 종료(더 기다리지 않음).

- `EyeCloseTimer` — 눈 감음 연속·누적 지속시간 추적(이 게임을 위해 만들어졌지만 독립 공용
  컴포넌트), `ClosedDuration`/`TotalClosedDuration`/`IsClosedContinuously(seconds)`/`ResetTimer()` 제공
- `MatchController` — 라운드 진행/최종 점수 집계. 승자가 정해지는 순간
  `ReportRoundResult(winner)` 한 번, 이어서 `LoadNextRound()` 한 번만 호출하면 됨(`winner`는
  `PlayerId?` — 무승부면 `null`)
- `ArtAssets` — 캐릭터/게임별 스프라이트 로더(`LoadCharacter`, `LoadStaringContest`)
- `HudWidgets` — HUD Canvas를 카메라 프레임에 맞추는 `ConfigureForGameCamera`, 이미지/텍스트 위젯 생성(`CreateImage`, `CreateText`)

## 12. 구현 완료 기준 (Acceptance Checklist)

- [ ] 눈을 뜨고 있으면 위험 게이지가 0을 유지한다
- [ ] 눈을 감으면 위험 게이지가 `Max(연속 비율, 누적 비율)`에 정확히 비례해서 차오른다
- [ ] 눈을 뜨는 순간 연속 위험 비율은 즉시 0으로 리셋되지만 누적 위험 비율은 유지된다
- [ ] `loseAfterClosedSeconds` 이상 연속으로 감으면 그 즉시 패배가 확정되고 반대쪽이 승리로 보고된다
- [ ] 눈을 감았다 뜨기를 반복해도 누적 감은 시간이 `loseAfterTotalClosedSeconds`를 넘기면 패배가 확정된다(무한 버티기 불가능)
- [ ] 정확히 같은 프레임에 둘 다 패배 조건을 만족하면 무승부로 처리된다
- [ ] 상대가 카메라 밖으로 나가면(트래킹 끊김) 그 순간 `ClosedDuration`만 0으로 리셋되고 `TotalClosedDuration`은 유지된다
- [ ] `maxMatchSeconds` 경과 시 아무도 안 감았으면 무승부로 종료된다
- [ ] P1 표정/전신이 `eye_fight_1`~`6` 6단계로 위험 비율에 맞춰 바뀐다(파츠 렌더링 없이 통짜 스프라이트 교체)
- [ ] P2 표정이 `face_eyes_closed_1of4`~`4of4` 4단계로 바뀌고 눈을 뜨면 기본 얼굴로 복귀한다
- [ ] 규칙 배너가 라운드 시작 시 표시되고 `ruleBannerSeconds` 후 자동으로 사라진다
- [ ] 라운드 종료 후 `resultDisplaySeconds` 뒤 자동으로 다음 씬으로 넘어간다
