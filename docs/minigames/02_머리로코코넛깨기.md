# 2. 머리로 코코넛 깨기 (Coconut Crack)

> 코드: `Assets/Scripts/Minigames/CoconutCrack/CoconutCrackGame.cs`, `CoconutBreakHud.cs`.
> 씬: `Assets/Scenes/CoconutCrack.unity`.

## 0. 한 줄 요약

머리 위 코코넛을 향해 양손을 계속 모았다 벌렸다 반복해서, 제한시간 안에 누가 더 많이
"타격 사이클"을 채우는지 겨루는 순수 반복 속도 경쟁.

## 1. 플레이어가 하는 일

| 동작 | 결과 |
|---|---|
| 양손을 머리 쪽으로 모음(손-머리 거리가 `hitDistance` 이하로 좁혀짐) | 타격 1회 인정, 코코넛이 쪼개지는 연출 재생 |
| 손을 다시 벌림(거리가 `releaseDistance` 이상으로) | 다음 타격을 셀 준비 완료 상태로 복귀 |
| 손을 완전히 벌리지 않고 살짝만 오갔다 다시 좁힘 | 타격으로 카운트되지 않음(반드시 release 임계값을 넘어야 다음 타격이 인정됨) |

## 2. 입력 신호 (PoseInputHub API)

| 신호 | 메서드/필드 | 이 게임에서의 의미 |
|---|---|---|
| 손-머리 거리 | `state.HandToHeadDistance()` | 양손 중점과 코(머리) 사이 거리, 몸통 길이로 정규화한 값 |
| 트래킹 여부 | `state.IsTracked` | false면 그 사람은 이번 프레임 타격 판정에서 제외 |

`PlayerPoseState`는 `PoseInputHub.Instance.Get(PlayerId.P1 / P2)`로 얻는다. 이 게임은 위 2개
외에 다른 신호(손 들기, 머리 기울기 등)를 쓰지 않는다.

## 3. 규칙 / 상태 흐름

이 게임도 돌던지기처럼 명시적 상태 머신 없이, 플레이어별로 독립된 "타격 준비" 플래그
(`readyToHit`)만 돌아간다(P1용 하나, P2용 하나 — 서로 완전히 독립).

```
[타격 준비됨] --거리 <= hitDistance--> 타격 카운트 증가 + 연출 재생, [타격 대기 중]으로
[타격 대기 중] --거리 >= releaseDistance--> [타격 준비됨]으로 복귀
```

매 프레임 처리 순서(플레이어별로 독립 실행):

1. `state.IsTracked`가 false면 이번 프레임은 아무것도 하지 않는다.
2. `readyToHit == true`이고 `HandToHeadDistance() <= hitDistance`이면: 타격 카운트 +1,
   HUD 갱신, 코코넛 쪼개짐 연출(`PunchCoconut`) 재생, `readyToHit = false`로 전환.
3. `readyToHit == false`이고 `HandToHeadDistance() >= releaseDistance`이면: `readyToHit = true`로
   복귀(다음 타격을 셀 준비 완료). 이 두 임계값 사이(`hitDistance` ~ `releaseDistance`)에서는
   상태가 바뀌지 않는다(히스테리시스 — 손을 살짝만 움직이는 것으로 여러 번 카운트되는 것을
   방지).

P1과 P2의 판정은 서로 완전히 독립이다.

## 4. 승리 / 패배 조건

`matchSeconds`(기본 15초) 경과 시점에 각자의 누적 타격 수를 비교해 **더 많이 타격한 쪽이
승리**한다. 정확히 같으면 무승부.

## 5. 화면 구도

- 카메라: `orthographicSize = 3`.
- 배경: 카메라 뷰를 채우는 배경 스프라이트 한 장(`image/games/coconut_break/background/`).
- 캐릭터: 화면 좌우에 P1/P2가 좌우 대칭 배치 - 관절 리깅 대신 `coconut_1~N` 프레임
  애니메이션으로 구동한다(`FrameAnimatedCharacter`). `coconut_1`이 대기 자세, 타격 인정
  순간 나머지 프레임이 `hitAnimSeconds` 동안 재생된 뒤 대기 자세로 복귀
- 코코넛: 각 플레이어 캐릭터의 자식 오브젝트로, 로컬 좌표 `(0, 1.6, 0)`(머리 위)에 고정
  배치되어 캐릭터를 따라다닌다.
- 좌우 소품: 각 플레이어 쪽에 "받침대" 소품(`P1/P2 StoneTable`)이 로컬 좌표 `(±2, -0.6, 1)`에
  배치되어 있다(장식용, 판정에는 영향 없음).

## 7. 연출 / 피드백

- **코코넛 쪼개짐**: 타격 인정 순간, 멀쩡한 코코넛 스프라이트를 잠깐 숨기고 좌/우로 쪼개진
  반쪽 두 장을 생성해 0.28초 동안 각각 반대 방향으로 이동·회전시키며 서서히 투명해지게
  한다. 끝나면 반쪽을 파괴하고 멀쩡한 코코넛을 다시 표시한다(매 타격마다 "깨졌다가 새
  코코넛이 나타나는" 것처럼 반복).
- **타격 캐릭터 동작**: `coconut_1~N` 프레임이 `hitAnimSeconds`(코코넛 쪼개짐 연출과 같은
  0.28초) 동안 재생된 뒤 대기 자세로 복귀한다. 프레임 애니메이션이 연결되지 않은 경우에만
  (폴백) 기존 방식대로 `face_coconut_bump_dizzy` 표정으로 잠깐 바뀌었다가 복귀한다 — 리깅
  머리가 프레임 애니메이션에 가려져 있는 동안은 표정 교체가 화면에 보이지 않으므로 둘을
  동시에 하지 않는다.
- **텍스트 피드백**: 타격 순간에는 텍스트 피드백 없음(코코넛 연출만). 라운드 종료 시에만
  승패 문구가 표시된 뒤 다음 라운드로 넘어간다.
- **사운드**: 미구현. TODO.

## 8. 조정 가능한 값

| 필드명 | 기본값 | 단위 | 의미 |
|---|---|---|---|
| `matchSeconds` | 15 | 초 | 라운드 제한시간 |
| `hitDistance` | 0.25 | 비율(몸통 길이 대비) | 손-머리 거리가 이 이하로 좁혀지면 타격 인정 |
| `releaseDistance` | 0.45 | 비율(몸통 길이 대비) | 손-머리 거리가 이 이상으로 벌어져야 다음 타격을 셀 준비 완료 |
| `resultDisplaySeconds` | 2.0 | 초 | 승패 문구 표시 후 다음 라운드로 넘어가기 전 대기 시간 |
| `coconutWidth` | 0.5 | 월드 유닛 | 코코넛(및 쪼개진 반쪽) 스프라이트 표시 폭 |
| `hitAnimSeconds` | 0.28 | 초 | 코코넛 쪼개짐 연출/(폴백)어지러운 표정/캐릭터 타격 프레임이 재생되는 시간(셋이 같은 길이로 맞춰져 있음) |

**프레임 애니메이션 연결됨**: 관절 리깅 대신 `coconut_1~6` 프레임을 타격 순간 재생하는

`coconut_1`부터 없는 번호가 나올 때까지 자동으로 세므로, 나중에 프레임을 더 늘리거나 줄여도

조정할 것(코드가 매 프레임 덮어쓰지 않는 필드다).

## 10. 예외 / 엣지 케이스

- **한쪽이 트래킹 안 됨(`IsTracked == false`)**: 그 사람은 손을 움직여도 타격이 카운트되지
  않는다(공격도 방어도 없는 게임이라 "카운트 정지"만 의미 있음).
- **손을 hitDistance와 releaseDistance 사이에서만 오감**: 상태가 바뀌지 않으므로 타격도
  release도 발생하지 않는다(히스테리시스 구간).
- **동점으로 시간 종료**: 무승부 처리(승자 없음으로 `MatchController`에 보고).
- **타격 연출 재생 중 라운드가 끝남**: 별도 정리 로직 없음 — 씬 전환 시 진행 중이던
  코루틴은 자동으로 사라진다.

## 11. 공용 의존성

- `PoseInputHub` / `PoseStreamReceiver` — 입력팀 담당, [게임_구동방식_정리.md](../게임_구동방식_정리.md) 참고
- `CavemanSilhouette` (+ `Assets/Prefabs/Caveman_P1.prefab`, `Caveman_P2.prefab`) — 캐릭터 리깅, 표정 교체(`SetFace`/`ResetFace`) API 포함(이 게임은 아직 미사용)
- `MatchController` — 라운드 진행/최종 점수 집계. 승자가 정해지는 순간
  `ReportRoundResult(winner)` 한 번, 이어서 `LoadNextRound()` 한 번만 호출하면 됨(`winner`는
  `PlayerId?` — 무승부면 `null`)
- `ArtAssets` — 프롭/캐릭터/게임별 스프라이트 로더(`LoadProp`, `LoadCoconutBreak` 등), 스프라이트 폭 맞추기(`FitWidth`)
- `HudWidgets` — HUD Canvas를 카메라 프레임에 맞추는 `ConfigureForGameCamera`, 이미지/텍스트 위젯 생성(`CreateImage`, `CreateText`)
