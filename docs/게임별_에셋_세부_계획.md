# 우가우가게임 에셋 제작 계획 + AI 생성 프롬프트

`우가우가게임_에셋_가이드`(체크리스트)와 실제 코드(`RuntimeSpriteFactory.cs`, `ArtAssets.cs`,
`CavemanSilhouette.cs`, 각 미니게임 스크립트, `Assets/Resources/`)를 대조해서 **지금 뭐가 이미
끝났고 뭐가 남았는지**부터 정리하고, 남은 것들은 게임별로 바로 이미지 생성 도구에 넣을 수 있는
프롬프트까지 붙였다.

다리/팔 관절 구조로 다시 짜야 하니 별도로 알려줄 것.

## 1. 공통 스타일 프롬프트 (모든 프롬프트 앞에 붙이는 접두어)

```
flat 2D cartoon game asset, thick bold black outline, solid flat single-color fill,
NO gradient, NO drop shadow, NO shading, minimal cel-shaded look, simple geometric
shapes, transparent PNG background, centered, game sprite icon style
```

- 캐릭터 파츠는 **흰색/연회색(#F2F2F2 근처) 단색**으로만 채운다 — 코드가
  `SpriteRenderer.color`로 P1=파랑(#3399FF)/P2=빨강(#FF4D40) 틴트를 실시간으로 입히므로
  색을 미리 넣으면 안 됨(틴트가 이상하게 섞임).
- 소품(돌/바나나/과일/코코넛/나무)은 고유색으로 그린다 (틴트 대상 아님).
- 외곽선 두께는 이미지 짧은 변의 **8~12%** — 코드 계산(원 9%, 캡슐 12%)과 톤을 맞추기 위함.
- 눈은 완전히 동그란 검은 점 2개, 하이라이트는 흰 점 1개 정도로 아주 단순하게 (필요한 파츠에만).

`head.png`를 이 표정 시트의 머리 비율에 **맞춰서** 그리는 게 낫다.

추가로 필요한 표정이 있다면:

| 파일 | 쓸 곳 |

**`face_mouth_open.png` 프롬프트**

[공통 스타일 접두어]

### 3-5. 자세따라하기 포즈 벽 — 이 게임만 유일하게 핵심 시각 요소가 없음

기획서(`우가우가게임_기획_프롬프트.md` 2번)의 핵심은 "상대 포즈 모양 구멍이 뚫린 벽이
다가온다"인데, 지금 코드에는 **벽이 아예 없다** — `wallApproachSeconds` 카운트다운
숫자만 뜬다(`PoseCopyGame.cs:112-118`). 6개 게임 중 기획 대비 시각적 구현이 가장 덜 된 곳.

| 파일 | 설명 |
|---|---|
| `wall_base.png` | 구멍 없는 벽 원본 (돌벽, 세로로 김) |
| `wall_hole_mask.png` | 포즈 실루엣 구멍 — 또는 코드에서 캐릭터 실루엣을 마스크로 동적 생성 |

포즈는 매번 플레이어가 즉석에서 만드는 것이라 **구멍 모양을 미리 그려둘 수 없다.**
`wall_base.png`만 그려두고 구멍은 코드에서 캡처된 포즈로 마스크 처리하는 게 맞는 접근 —
그림으로 해결할 부분이 아니라 코드 작업이다.

**`wall_base.png` 프롬프트**
```
[공통 스타일 접두어]
a single vertical stone wall slab, tall rectangle with slightly irregular rocky
edges, flat solid gray fill (#8C8C8C tone), thick black outline, simple flat
cartoon stone block texture lines kept minimal, no hole no opening, aspect ratio
roughly 1:2 (tall), isolated single game asset on transparent background
```

### 3-7. 우선순위 요약

## 4. 임포트 체크리스트 (그림 그린 다음)

- 배경 투명 PNG. 도형 바깥은 완전 투명이어야 함.
- 여기 적힌 픽셀 수는 절대값이 아니라 **가로:세로 비율만** 지키면 됨 — 더 크고 선명하게
  그리려면 비율 그대로 4~8배 키워도 됨(Unity에서 Pixels Per Unit만 맞추면 인게임 크기 동일).
- 파일당 하나의 파츠. 몸통/머리/손이 한 이미지에 붙어 있으면 안 됨 — 코드가 각각을 독립된
  Transform으로 움직임.
- Texture Type은 `Sprite (2D and UI)`로 지정.
- 완성된 파일은 `Assets/Resources/Props/`(캐릭터 파츠, 나무, 과일, 트랙) 또는
  `Assets/Resources/UI/`(결과 패널)에 넣을 것 — `ArtAssets.LoadProp`/`LoadUi`가 그 경로를
  그대로 찾는다.
- 그림이 다 모이면 아래 코드 자리를 실제 `ArtAssets.LoadProp(...)` 호출로 바꾸는 작업이
  필요함 — 그때 알려주면 이어서 처리:
  - `CavemanSilhouette.cs:29-32` (`RuntimeSpriteFactory.CreateCapsule/CreateCircle` 3곳)
  - `FruitJumpGame.cs:88,99` (`RuntimeSpriteFactory.CreateCapsule/CreateCircle` 2곳)
  - `PoseCopyGame.cs:64` (`RuntimeSpriteFactory.CreateCapsule` 1곳)
