# 게임별 에셋 현황과 개선 계획

최종 점검: 2026-07-30. Unity가 실제 사용하는 파일은 `pc-game/Assets/Resources`, 제작 원본은
저장소 루트의 `image`에 있다. 현재 5개 게임의 배경·HUD·캐릭터 파츠·주요 소품은 모두 임포트되어
있으며 씬 또는 프리팹에 고정 배치됐다. 새로 기획된
[소리지르기](minigames/07_소리지르기.md)·[깃털날기](minigames/08_깃털날기.md) 2종은 아직
에셋 제작·임포트 전이다(아래 표 참고). 원래 있던 자세따라하기(PoseCopy)는 구현 난이도
문제로 폐기되어 코드/씬/`Resources/PoseMatch`/원본 이미지(`image/games/pose_match`)를
전부 삭제했다.

## 현재 구현 현황

| 영역 | 상태 | Unity 편집 위치 |
|---|---|---|
| 시작 화면 | 배경, 로고, 버튼 4종 완료 | `Assets/Prefabs/StartScreenCanvas.prefab` |
| 캐릭터 | P1/P2 전신 파츠와 팔 2관절 리깅 완료 | `Assets/Prefabs/Caveman_P1/P2.prefab` |
| 돌던지기 | 새 근거리 분할 배경·돌·피격 HUD·타이머 완료. 손 방향별 투척 애니메이션과 찡그린 얼굴 오버레이 연결 필요 | `Scenes/StoneThrow > EditableLayout` |
| 과일따기 | 배경, 과일 3종, 점수 HUD 완료 | `Scenes/FruitJump > EditableLayout` |
| 코코넛깨기 | 배경, 테이블, 코코넛/파편, 타격 HUD 완료 | `Scenes/CoconutCrack > EditableLayout` |
| 돌 or 바나나 | 배경, 돌/바나나, 수풀, 턴/HUD 완료 | `Scenes/StoneOrBanana > EditableLayout` |
| 눈빛싸움 | 배경, 얼굴, 충돌 이펙트, 위험 게이지 완료 | `Scenes/StaringContest > EditableLayout` |
| 최종 결과 | 결과 문구와 다시 시작 버튼 완료 | `Scenes/Hub > ResultScreenCanvas` |
| 소리지르기 *(기획 단계)* | 문서만 완료, 배경/표정/HUD 전부 미제작, 씬 없음 | `Scenes/ScreamDuel`(미생성) |
| 깃털날기 *(기획 단계)* | 배경/절벽/HUD 네임플레이트, P1/P2 캐릭터 점프·날갯짓 7컷씩 제작·임포트 완료, 게이지 채움 이미지·씬·게임 로직은 아직 없음 | `Scenes/FeatherFlight`(미생성) |

캐릭터, 배경, HUD는 더 이상 Play 때 생성되지 않는다. 날아가는 투사체, 깨진 코코넛 조각,
다가오는 자세 벽은 반복 사용되는 일회성 연출이므로 런타임 생성이 정상이다.

## Resources 구조

```text
Assets/Resources/
├── Characters/       P1/P2 몸 파츠와 표정
├── Props/            돌, 바나나, 코코넛, 과일
├── UI/               시작 화면과 공용 UI
├── StoneThrow/
├── FruitJump/
├── CoconutBreak/
├── StoneOrBanana/
├── StaringContest/
├── ScreamDuel/       (계획, 미생성) 소리지르기 배경/HUD
└── FeatherFlight/    배경/절벽/HUD 네임플레이트 임포트 완료, 씬은 아직 미생성
```

`ArtAssets.cs`가 위 경로의 스프라이트를 로드한다. 같은 기능의 이미지는 공용 Props/UI를 우선
재사용하고, 게임 고유 이미지에만 게임별 폴더를 쓴다.

## 다음 품질 개선 우선순위

1. 각 게임 HUD의 글꼴, 외곽선, 여백을 같은 규칙으로 통일한다.
2. 캐릭터 어깨/팔꿈치 피벗을 실제 카메라 포즈와 비교해 미세 조정한다.
3. 16:9 외 화면비에서 앵커와 Safe Area를 점검한다.
4. 투사체/벽/코코넛 파편을 필요하면 오브젝트 풀로 바꿔 생성 비용을 줄인다.
5. 효과음, 배경음, 화면 흔들림, 파티클을 추가한다.

**MatchScoreboard 제거됨**: 라운드별 승패를 아이콘으로 보여주는 매치 결과판(`MatchScoreboardHud`)은
화면에 띄우지 않기로 결정해 5개 씬(StoneThrow, CoconutCrack, StaringContest, StoneOrBanana,
FruitJump)에서 전부 제거했다. 관련 컴포넌트(`MatchScoreboardHud.cs`)와 씬 생성 코드의 호출부도
같이 삭제했다 — 더 이상 존재하지 않는 기능이므로 위 우선순위 목록에서도 뺐다.

실제 배치와 이미지 교체 절차는 [UNITY_EDITOR_편집_가이드.md](UNITY_EDITOR_편집_가이드.md)를
따른다. `Tools > Uga Uga > Rebuild All Editable Scene Layouts...`는 수동 배치를 덮어쓰는 복구
도구이므로 평소에는 실행하지 않는다.
