# 멀티플레이 실행 명령어

같은 LAN에서 Unity를 두 대 실행하는 2인 플레이 기준입니다. **게임 판정은 호스트 Unity가
담당하므로 P1·P2의 vision-server는 둘 다 호스트 PC로 전송해야 합니다.**

## 1. 호스트 IP 확인

호스트 PC의 PowerShell에서:

```powershell
ipconfig
```

사용 중인 Wi-Fi 또는 이더넷의 `IPv4 주소`를 확인합니다. 예시는 `192.168.0.12`입니다.

## 2. 최초 환경 설정

P1·P2 PC에서 각각 한 번 실행합니다.

```powershell
cd C:\path\to\leftover\vision-server
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 3. vision-server 실행

### P1이 호스트 PC에서 카메라를 켜는 경우

```powershell
cd C:\path\to\leftover\vision-server
.\.venv\Scripts\python.exe main.py --pc-ip 127.0.0.1 --player-id p1 --voice
```

### P2 PC

`<호스트_IP>`를 1단계에서 확인한 주소로 바꿉니다.

```powershell
cd C:\path\to\leftover\vision-server
.\.venv\Scripts\python.exe main.py --pc-ip <호스트_IP> --player-id p2 --voice
```

### P1 카메라도 별도 PC에서 실행하는 경우

P1도 `127.0.0.1` 대신 같은 호스트 IP를 사용합니다.

```powershell
.\.venv\Scripts\python.exe main.py --pc-ip <호스트_IP> --player-id p1 --voice
```

`--voice`는 ScreamDuel 마이크 입력을 같은 Python 프로세스에서 처리합니다. 별도 녹음
프로그램을 실행할 필요가 없습니다.

## 4. 간편 런처

IP와 플레이어 번호를 질문받아 실행하려면:

```powershell
.\.venv\Scripts\python.exe run_team_test.py
```

인자를 한 번에 지정하려면:

```powershell
# P1
.\.venv\Scripts\python.exe run_team_test.py --pc-ip <호스트_IP> --player-id p1

# P2
.\.venv\Scripts\python.exe run_team_test.py --pc-ip <호스트_IP> --player-id p2
```

`run_team_test.py`는 마이크를 기본 활성화합니다. 카메라만 시험할 때만 `--no-voice`를
사용합니다.

## 5. Unity 연결

1. 두 PC에서 `pc-game/Assets/Scenes/Hub.unity`를 실행합니다.
2. 판정을 담당할 PC에서 `2인 플레이 → 호스트로 시작`을 선택합니다.
3. 다른 PC에서 `2인 플레이 → 참가`, 호스트 IP 입력 후 접속합니다.
4. 연결 완료 뒤 호스트가 게임을 시작합니다.

## 6. 마이크 확인과 장치 변경

마이크만 `0~100` 게이지로 확인:

```powershell
.\.venv\Scripts\python.exe test_scream_mic.py
```

사용 가능한 입력 장치 확인:

```powershell
.\.venv\Scripts\python.exe main.py --list-audio-devices
```

기본 마이크가 잘못 선택되었을 때:

```powershell
.\.venv\Scripts\python.exe main.py --pc-ip <호스트_IP> --player-id p2 --voice --voice-device <장치번호>
```

노트북 마이크 배열은 기본적으로 모든 입력 채널을 합산합니다. 특별한 문제가 있을 때만
`--voice-channels <채널수>`로 제한합니다.

## 7. 포트와 점검

호스트 PC의 방화벽에서 다음 인바운드 포트를 허용해야 할 수 있습니다.

| 포트 | 프로토콜 | 용도 |
|---:|---|---|
| 9100 | UDP | 포즈·얼굴·마이크 음량 |
| 9101 | UDP | 로딩 화면 카메라 프리뷰 |
| 9200 | TCP | Unity 호스트·클라이언트 게임 이벤트 |

카메라 창에서 다음을 확인합니다.

- 관절 점이 표시되는가
- 하단 `MIC 0~100` 게이지가 움직이는가
- `PEAK`가 소리를 낼 때 증가하는가

카메라 창의 `R`은 최고값 초기화, `Q`는 종료입니다. 한 PC에서 같은 플레이어 명령을 두 번
실행하면 카메라·마이크 장치 충돌이 날 수 있으므로 기존 창을 먼저 종료합니다.
